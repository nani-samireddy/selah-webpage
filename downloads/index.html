FROM DOWNLOAD TO SERVICE

A little setup.
Then you’re ready.

Unzip collections first. Import each resource
in its matching Selah workspace.

Bundled Bible packages

Libraries → Bible → Import translation. These three versions already come with Selah; import only a missing version.

Repository XML Bibles

Download the original XML. Import requires a Selah build with Beblia XML support; these files are separate from Selah JSON packages.

Song collections

Libraries → Songs → Import song. Choose each JSON file separately. ZIP collections aren’t imported directly.

Service presets

Programs → Import. Choose the .churchprogram file, then update the service title, date, and content.

Templates

Libraries → Templates → Import. Choose the .churchtemplate file, then apply it to compatible lyrics or Scripture.

Made to be used with care.

Song collections include original demonstration lyrics and a public-domain hymn. They are not a licensed commercial worship catalog. Bible packages retain their source attribution and license notices. Layouts and service presets are editable starting points; preview your content before presenting.

Inter and Noto Sans Telugu are included with Selah. The Warm paper template uses Georgia; choose another serif font if it isn’t installed.
