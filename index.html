Church presentation software, built around the service.

Selah brings song lyrics, Bible passages, images, videos, and custom slides into saved church service programs. Prepare content in Programs and Design, then use Present for live and upcoming slides, audience controls, and private speaker notes.

Multilingual songs support paired lyrics and translations. English, Telugu, and Hindi Bible libraries are bundled for offline use. The resource library includes song collections, service presets, editable templates, and original XML Bible files with source attribution.

Selah is a native desktop app targeting macOS and Windows. It is currently a development preview, with Windows release validation ongoing and public app downloads being prepared. Follow the Selah project on GitHub for development updates.

Getting to know Selah.

Ask a question on GitHub
What is Selah?

Selah is a native desktop church presentation app. It brings song lyrics, Bible passages, media, and custom slides into service programs, with separate audience and speaker outputs.

Does Selah work offline?

Your libraries and prepared services are stored on your computer. Bundled Bible translations work offline. Downloading additional fonts requires internet access; downloaded fonts can be reused offline.

Can we present in more than one language?

Yes. Songs support paired original and translated lyrics, with bilingual layouts. The bundled Bible library includes English WEB, Telugu IRV, and Hindi IRV translations.

Can I control the service from my phone?

Selah includes a browser controller that pairs with a QR code on a trusted local network. Controllers can navigate slides and use audience blackout. A separate read-only speaker view provides notes and upcoming content. Physical-device validation is ongoing.

When can I download the app?

Selah is currently a working development preview. Public downloads and supported release requirements will be shared when ready. Follow the GitHub project for progress.
